# Release Notes

Short checklist for the release drill sandbox. This file lands on the `drill/notes` branch and is merged into `main` via pull request.

## Release Checklist

- [ ] Verify `main` is up to date and the default branch health is good
- [ ] Cut a feature branch (e.g. `drill/notes`) from `main` before making changes
- [ ] Add or update `RELEASE_NOTES.md` with a heading and checkbox items
- [ ] Open a pull request titled "Add release drill checklist" into `main`
- [ ] Leave a reviewer comment on the change and submit it as a comment review (not an approval)
- [ ] Request an automated Copilot code review on the pull request
- [ ] Merge the pull request and confirm the commit SHA on `main`
