# Release Drill Checklist

A short checklist to run through before, during, and after the release drill.

## Before the drill

- [ ] Confirm the drill window and who is participating
- [ ] Create a branch for any drill changes

## During the drill

- [ ] Open the smoke-test workflow and run it on the default branch
- [ ] Verify the smoke-test run finishes successfully
- [ ] Review the open pull requests and confirm none are unintended

## After the drill

- [ ] Confirm the tracking issue and its sub-issues are up to date
- [ ] Record the smoke-test run id and conclusion
- [ ] Note any follow-up actions for the next drill
